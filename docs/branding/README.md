# Arihna branding assets

Approved on 2026-08-29.

## Official mark

The Arihna icon is the approved monogram **A** integrating:
- a minimal minaret,
- a crescent,
- three radiating sound waves evoking the adhan.

No sacred text, Quran verse, divine name, or generated Arabic calligraphy is used in the icon.

## Official palette

- Green: `#0F5132`
- Gold: `#D4AF37`
- Off-white: `#FAFAF6`

## Android launcher assets

Legacy raster sizes:
- mdpi: 48×48 px
- hdpi: 72×72 px
- xhdpi: 96×96 px
- xxhdpi: 144×144 px
- xxxhdpi: 192×192 px

Adaptive icons use separate background/foreground layers in `mipmap-anydpi-v26/`.
API 33+ overrides in `mipmap-anydpi-v33/` add the monochrome layer for Android themed icons. The Android notification icon is a monochrome vector because Android masks/tints small notification icons.
